# Самостоятельная работа №1 — финальная версия
## У КАЖДОГО шага есть объяснение. Без исключений.

**Формат каждого шага одинаковый:**
- **Что печатаем** — точный текст
- **Что это** — определение элемента языка
- **Зачем** — зачем он тут нужен и что будет, если его не написать

## ЧАСТЬ A. Создание проекта

### Шаг 1
**Что печатаем:** `Win + R`, затем `cmd`, затем Enter.
**Что это:** открытие командной строки Windows.
**Зачем:** лабораторная требует создать проект именно через CLI (`dotnet`), а не через Visual Studio. Всё взаимодействие — через cmd.

### Шаг 2
**Что печатаем:** `cd C:\` → Enter.
**Что это:** команда `cd` (*change directory*) — «сменить папку». `C:\` — корень диска C.
**Зачем:** по умолчанию cmd открывается в папке пользователя. Мы хотим предсказуемое место для всех работ.

### Шаг 3
**Что печатаем:** `mkdir Labs` → Enter.
**Что это:** `mkdir` (*make directory*) — создать папку.
**Зачем:** получим одну папку `Labs` для всех лабораторных семестра.

### Шаг 4
**Что печатаем:** `cd Labs` → Enter.
**Что это:** переход внутрь папки `Labs`.
**Зачем:** все следующие команды будут выполняться внутри `C:\Labs\`.

### Шаг 5
**Что печатаем:** `dotnet new console --use-program-main -n ShopApp` → Enter.
**Что это:** команда создания проекта. Разбор:
- `dotnet` — утилита .NET SDK;
- `new` — создать новый проект;
- `console` — по шаблону «консольное приложение»;
- `--use-program-main` — **важный флаг**, включает классическую точку входа `static void Main`. Без него .NET 8 создаст файл без явного `Main`;
- `-n ShopApp` — имя проекта.
**Зачем:** нам нужна именно классическая точка входа по требованию лабораторной.

### Шаг 6
**Что печатаем:** `cd ShopApp` → Enter.
**Что это:** переход в папку созданного проекта.
**Зачем:** команда `dotnet run` работает относительно текущей папки.

### Шаг 7
**Что делаем:** в проводнике открываем `C:\Labs\ShopApp`, включаем показ расширений файлов.
**Что это:** настройка отображения в проводнике.
**Зачем:** без этого файл `Product.cs` будет показан как `Product`, и при переименовании легко получить `Product.cs.txt`.

## ЧАСТЬ B. Класс `Product`

### Шаг 8
**Что делаем:** создаём пустой текстовый файл, переименовываем в `Product.cs`, открываем в блокноте.
**Что это:** пустой файл для нового класса.
**Зачем:** в C# принято «один класс — один файл», и имя файла = имя класса.

### Шаг 9
**Что печатаем:**
```
namespace ShopApp;
```
Затем Enter.
**Что это:**
- `namespace` — ключевое слово «объявляю пространство имён»;
- `ShopApp` — имя пространства (совпадает с именем проекта);
- `;` — это **file-scoped namespace**, современный синтаксис C# 10+.
**Зачем:** пространство имён объединяет классы в группу. Класс `Program` уже в `ShopApp`, значит наш `Product` тоже попадёт туда — и в `Program.cs` не понадобится `using`. Без этого программа класс не найдёт.

### Шаг 10
**Что печатаем:** ничего, просто Enter — пустая строка.
**Что это:** пустая строка-разделитель.
**Зачем:** визуально отделяет «шапку» файла от тела класса. Компилятор её игнорирует, нужна человеку для читаемости.

### Шаг 11
**Что печатаем:**
```
public class Product
```
Enter в конце, **без `;` и без `{`**.
**Что это:**
- `public` — модификатор доступа «доступен отовсюду»;
- `class` — ключевое слово «объявляю класс»;
- `Product` — имя класса (PascalCase, с большой буквы).
**Зачем:** `public` нужен, чтобы `Program.cs` мог создавать объекты этого класса. Имя класса задаёт тип — позже напишем `Product product = new Product();`. Без `;`, потому что следом идёт блок с `{ }`, а не инструкция.

```
Затем Enter.
**Что это:** открывающая фигурная скобка — начало тела класса.
**Зачем:** всё между этой `{` и парной `}` в конце файла станет содержимым класса (поля, методы). Без закрывающей скобки компилятор скажет `} expected`.

```
Затем Enter.
**Что это:**

- `public` — поле доступно снаружи класса;
- `string` — **тип данных** «строка текста»;
- `Name` — имя поля;
- `;` — конец объявления.
**Зачем:** поле хранит название товара. `public` нужен, чтобы в `Program.cs` написать `product.Name = "..."`. У поля **нет скобок и нет тела** — оно только хранит значение.

**Зачем:** цена может быть 99.99 — тип `int` не подошёл бы. `double` хранит дробные числа и легко принимает целые (30000 автоматически станет 30000.0).

**Зачем:** можно проверять `if (product.IsAvailable) ...`. Тип `bool` принимает строго два значения.
